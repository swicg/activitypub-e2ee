# ActivityPub E2EE

This is the repository for the ActivityPub E2EE task force of the [Social Web Community Group](https://www.w3.org/community/socialcg/) of the [W3C](https://w3.org/).

## Authors:

- Evan Prodromou [acct:evanprodromou@socialwebfoundation.org](acct:evanprodromou@socialwebfoundation.org)
- Tom Coates
- Mallory Knodel

## Participate

- [Issue tracker](https://github.com/swicg/activitypub-e2ee/issues)
- [Discussion forum](https://activitypub.space/category/30/e2ee-task-force) on [activitypub.space](https://activitypub.space/)
- [Mailing list](https://lists.w3.org/Archives/Public/public-swicg/) (use `[e2ee]` in the subject of your message)
- [Meeting](https://www.w3.org/events/meetings/5f3b9664-5b78-46ea-b7cf-f7a8dde3fa83/) on the 4th Tuesday of the month. The agenda is a GitHub issue with the [agenda](https://github.com/swicg/activitypub-e2ee/issues?q=is%3Aissue+state%3Aopen+label%3Aagenda) tag. Add a comment to the issue to add an item to the agenda!
